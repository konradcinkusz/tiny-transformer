TinyTransformer encoder visualizer

A transformer encoder block, written from scratch in C# with no ML framework, run live in your browser. This is not a trained language model - weights are random on every request - it exists to show what each piece of a transformer actually computes.

Tokens

Each distinct character seen in the input gets the next free token id, in order of first appearance.

Token embeddings

Random (untrained) lookup vector per token id - shape [tokens × d_model].

Positional encoding

Sinusoidal, added to the embeddings before attention - without it, order carries no information (see the "why" in the README).

Attention weights

Row = query token, column = attends-to token. Each row sums to 1.

Encoder block output

After self-attention, residual + LayerNorm, feed-forward, residual + LayerNorm - shape [tokens × d_model].

TinyTransformer is an educational project. See the README for what it does and does not do.
